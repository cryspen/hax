# Manual

The hax manual is available in several versions:

- [**Branch `main`**](main/) — the manual for the current development version of
  hax, built from the latest commit on `main`.
- [**Version v0.3.7**](v0.3.7/) — the manual for the latest hax
  [release](https://github.com/cryspen/hax/releases).

If you installed hax from a release, pick the matching version; if you are
tracking `main`, use the `main` manual.
